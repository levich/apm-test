# Imports and backups

Administrator-only. Export a read-only NPM/NPMPlus snapshot with apm export-npm, upload JSON/ZIP and preview it. The report lists supported and skipped objects; unknown settings are not guaranteed to transfer. Create disabled drafts stores inactive resources; Activate creates configuration and queues apply. Resolve domain/reference conflicts.

Set apm backup-password locally before backups: minimum 16 characters. The backup button queues an encrypted .apm archive. Archives contain the database and keys; store them separately. Restore with apm restore ARCHIVE while manager and worker are stopped, supplying the password; the previous directory is preserved. After startup confirm validation and application. [CLI](cli.md)
