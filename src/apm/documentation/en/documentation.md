# Documentation

The guide is packaged with APM and works offline. RU/EN switches both the panel and articles. The left contents menu opens sections; Read the guide links in field help lead to a setting. Reading requires login; each section explains edit permissions.

Canonical Markdown files are in src/apm/documentation/ru and en. The panel, wheel/Docker and repository links use this one set. Markdown HTML is disabled. Example secrets are placeholders to replace with your own values.
