# Обзор

Показывает количество ресурсов, состояние агента, подтверждённое поколение Angie, возможности сборки и последние операции. Доступен всем вошедшим пользователям. Сначала проверьте связь с агентом, затем завершение применения. Отсутствие контакта worker с агентом означает неизвестное состояние, а не подтверждённую работу хостов. Доступность backend показана отдельно в таблице прокси-хостов.
