# Документация

Руководство включено в пакет APM и работает без интернета. Переключатель RU/EN выбирает язык панели и статей. Оглавление слева открывает разделы; ссылки «Открыть руководство» в подсказках формы ведут к настройке. Для просмотра нужен вход, права на изменение описываются в каждом разделе.

Канонические Markdown-файлы находятся в src/apm/documentation/ru и en. Один набор используется панелью, wheel/Docker и ссылками репозитория. HTML из Markdown отключён. Секреты в примерах — только обозначения, их нужно заменить своими.
