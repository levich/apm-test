# Аудит

Администраторский журнал изменений и событий входа. GET /api/v1/audit возвращает до 200 последних записей: created_at, actor, action, object_id, detail. API доступен только admin.

Используйте для ответа «кто изменил настройку», а «Операции» — для результата применения. Детали содержат названия действий и идентификаторы, без паролей и ключей. Удаление объекта не удаляет прошлые записи. Для восстановления доступа используйте локальный CLI с проверкой сервера.
