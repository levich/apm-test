# Политики TLS

Общие настройки входящего TLS. Создайте политику, при необходимости ECH, затем подключите к SSL-хосту. Не управляет проверкой TLS backend. Часть функций зависит от сборки Angie; изменяет администратор.

## Настройки

### `name`

<!-- setting:name -->
Название ресурса для поиска и выбора в панели, например test. Не меняет его ID и связанные ресурсы.

Формат: `string`. По умолчанию: `обязательно`. Ограничения: minLength=1; maxLength=128.

Пример: `"test"`.

### `enabled`

<!-- setting:enabled -->
Включает объект в генерируемую конфигурацию. Выключенный объект сохраняется в панели. Изменение вступает в силу после сохранения и успешного применения.

Формат: `boolean`. По умолчанию: `true`.

Пример: `true`.

### `protocols`

<!-- setting:protocols -->
Разрешённые версии входящего TLS. Нельзя оставить список пустым. Обычно используйте TLSv1.2 и TLSv1.3.

Формат: `array`. По умолчанию: `["TLSv1.2", "TLSv1.3"]`. Ограничения: TLSv1.2 / TLSv1.3.

Пример: `["TLSv1.2", "TLSv1.3"]`.

### `ciphers`

<!-- setting:ciphers -->
Строка шифров OpenSSL для ssl_ciphers. Пример HIGH:!aNULL:!MD5:!3DES. Не является настройкой шифров TLS 1.3.

Формат: `string`. По умолчанию: `"HIGH:!aNULL:!MD5:!3DES"`.

Пример: `"HIGH:!aNULL:!MD5:!3DES"`.

### `curves`

<!-- setting:curves -->
Группы обмена ключами ssl_ecdh_curve; auto выбирает библиотека TLS. Допустимость проверяется angie -t.

Формат: `string`. По умолчанию: `"auto"`.

Пример: `"auto"`.

### `ocsp`

<!-- setting:ocsp -->
Включает OCSP stapling и проверку stapling для выбранного сертификата. Нужны совместимый CA, цепочка и сетевой доступ к responder.

Формат: `boolean`. По умолчанию: `false`.

Пример: `false`.

### `certificate_compression`

<!-- setting:certificate_compression -->
Сжатие TLS-сертификатов. Требует соответствующей возможности Angie; не сжимает HTTP-ответы.

Формат: `boolean`. По умолчанию: `false`.

Пример: `false`.

### `ech_id`

<!-- setting:ech_id -->
Выбор готовой конфигурации ECH. Ключ активируется после подтверждения DNS; требуются совместимые Angie и TLS-библиотека.

Формат: `string / null`. По умолчанию: `null`.

Пример: `"<resource-id>"`.

## Пример работы

Создайте ресурс с понятным названием, заполните обязательные поля и сохраните. Проверьте завершение apply в «Операциях». При ошибке angie -t исправьте параметры или зависимости; прежняя рабочая конфигурация сохраняется. Observer читает данные, admin удаляет ресурсы, которые больше не используются.
