# Статика / PHP

Статические сайты и PHP через существующий FPM. Создайте каталог под APM_DATA_DIR/sites, разместите файлы, затем настройте домены и root_id. Форма не загружает файлы и не запускает FPM. Управляет администратор.

## Настройки

### `name`

<!-- setting:name -->
Название для поиска сайта в панели, например «Сайт компании». Входящие запросы сопоставляются с полем «Доменные имена». Название не задаёт каталог с файлами сайта.

Формат: `string`. По умолчанию: `обязательно`. Ограничения: minLength=1; maxLength=128.

Пример: `"test"`.

### `enabled`

<!-- setting:enabled -->
Включает сайт в конфигурацию Angie после сохранения и успешного применения. Выключение убирает конфигурацию сайта, сохраняя его настройки и файлы; отдельный сервис PHP-FPM при этом продолжает работать.

Формат: `boolean`. По умолчанию: `true`.

Пример: `true`.

### `domains`

<!-- setting:domains -->
Доменные имена этого сайта, по одному на строке, например www.example.com. Указывайте без протокола, порта и пути. DNS-записи настройте отдельно, направив их на Angie. Все имена используют один каталог сайта и один сертификат.

Формат: `array`. По умолчанию: `обязательно`. Ограничения: minItems=1.

Пример: `["app.example.com"]`.

### `root_id`

<!-- setting:root_id -->
Имя подкаталога в APM_DATA_DIR/sites, а не полный путь. Например, company соответствует /data/sites/company при стандартном каталоге данных. Допустимы 1–80 латинских букв, цифр, символов _ и -. Разместите или подключите файлы в этот каталог с доступом на чтение для Angie. Сохранение формы не загружает файлы. Angie ищет сначала index.html, затем index.php.

Формат: `string`. По умолчанию: `обязательно`.

Пример: `"company"`.

### `certificate_id`

<!-- setting:certificate_id -->
Выберите сертификат, покрывающий все доменные имена сайта. Предварительно запросите или загрузите его на странице «Сертификаты». Пустой выбор оставляет только HTTP. Готовый сертификат добавляет HTTPS без автоматического перенаправления с HTTP. Если выбранный сертификат ещё не готов, сайт возвращает HTTP 503 до готовности сертификата и успешного применения конфигурации.

Формат: `string / null`. По умолчанию: `null`.

Пример: `"<resource-id>"`.

### `php_upstream`

<!-- setting:php_upstream -->
FastCGI-адрес уже работающего PHP-FPM, например php-fpm:9000 или 192.0.2.10:9000, без http:// и пути. Angie должен иметь доступ к FPM по сети, а скрипты должны быть доступны обоим по одинаковому абсолютному пути, например /data/sites/company/index.php. Настройка не запускает PHP-контейнер. Оставляйте пустым только для статики: PHP-файлы не будут исполняться и могут отдаваться как исходный текст.

Формат: `string / null`. По умолчанию: `null`.

Пример: `"php-fpm:9000"`.

### `directory_index`

<!-- setting:directory_index -->
Показывает список файлов каталога, когда в нём нет index.html и index.php. По умолчанию выключено: каталог без индексной страницы обычно возвращает 403. Включайте для публичного файлового каталога, содержимое которого можно показывать посетителям. Эта настройка не добавляет авторизацию и не защищает отдельные файлы.

Формат: `boolean`. По умолчанию: `false`.

Пример: `false`.

### `fancyindex`

<!-- setting:fancyindex -->
Включает оформленный список файлов каталога через модуль fancyindex Angie, когда нет индексной страницы. Модуль должен быть доступен в сборке Angie; переключатель его не устанавливает. Без модуля применение завершится ошибкой, а прежняя рабочая конфигурация сохранится. Имена файлов в списке видны посетителям.

Формат: `boolean`. По умолчанию: `false`.

Пример: `false`.

## Пример работы

Создайте ресурс с понятным названием, заполните обязательные поля и сохраните. Проверьте завершение apply в «Операциях». При ошибке angie -t исправьте параметры или зависимости; прежняя рабочая конфигурация сохраняется. Observer читает данные, admin удаляет ресурсы, которые больше не используются.
