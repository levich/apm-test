# Правила GeoIP

Географические ограничения по стране/ASN. Задайте учётные данные MaxMind, обновите MMDB и подключите политику к хосту. Нужен модуль GeoIP2. Условия private/unknown задаются явно. Доступно администратору.

## Настройки

### `name`

<!-- setting:name -->
Название ресурса для поиска и выбора в панели, например test. Не меняет его ID и связанные ресурсы.

Формат: `string`. По умолчанию: `обязательно`. Ограничения: minLength=1; maxLength=128.

Пример: `"test"`.

### `enabled`

<!-- setting:enabled -->
Включает объект в генерируемую конфигурацию. Выключенный объект сохраняется в панели. Изменение вступает в силу после сохранения и успешного применения.

Формат: `boolean`. По умолчанию: `true`.

Пример: `true`.

### `countries`

<!-- setting:countries -->
Коды стран ISO 3166-1 alpha-2 в верхнем регистре, по одному на строке, например RU или DE. Нужна загруженная база GeoIP.

Формат: `array`. По умолчанию: `[]`.

Пример: `["DE"]`.

### `asns`

<!-- setting:asns -->
Номера автономных систем без префикса AS, по одному на строке. Диапазон 1–4294967295. Нужна база ASN.

Формат: `array`. По умолчанию: `[]`.

Пример: `[64512]`.

### `database_version`

<!-- setting:database_version -->
Системный идентификатор версии загруженных GeoIP-баз. Обновляется действием «Обновить MMDB»; вручную не задаётся.

Формат: `string`. По умолчанию: `""`.

Пример: `"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"`.

### `mode`

<!-- setting:mode -->
allow разрешает выбранные страны/ASN и запрещает остальные; deny запрещает выбранные. Отдельно задайте поведение для private и unknown адресов.

Формат: `string`. По умолчанию: `"deny"`. Ограничения: allow / deny.

Пример: `"deny"`.

### `allow_private`

<!-- setting:allow_private -->
Разрешать частные и локальные IP независимо от географических правил. Полезно для внутренних сервисов и проверок.

Формат: `boolean`. По умолчанию: `true`.

Пример: `true`.

### `allow_unknown`

<!-- setting:allow_unknown -->
Разрешать адреса, для которых база не определила страну/ASN. Отключение может закрыть доступ новым или неописанным сетям.

Формат: `boolean`. По умолчанию: `true`.

Пример: `true`.

## Пример работы

Создайте ресурс с понятным названием, заполните обязательные поля и сохраните. Проверьте завершение apply в «Операциях». При ошибке angie -t исправьте параметры или зависимости; прежняя рабочая конфигурация сохраняется. Observer читает данные, admin удаляет ресурсы, которые больше не используются.

## Секреты

### `account_id`

<!-- credential:account_id -->
MaxMind account ID для загрузки GeoLite2-баз Country и ASN.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `license_key`

<!-- credential:license_key -->
MaxMind license key с правом загрузки баз, используемый действием обновления MMDB.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.
