# Конфигурационные файлы

Пользовательские ресурсы компилируются в отдельные файлы внутри revisions/ID/http и stream. Название берётся из поля «Название», кириллица транслитерируется, небезопасные символы заменяются, совпадения получают стабильный суффикс ID. Например test.proxy.conf, test.redirect.conf, test.stream.conf, test.site.conf, test.upstream.conf. Одна upstream-группа может иметь отдельные HTTP и stream варианты.

Системные точки входа angie.conf/http.conf/stream.conf и стандартные PEM-пути сохраняются. Все include абсолютные и относятся к конкретной неизменяемой ревизии. Переименование создаёт новый файл в новой ревизии; старую не изменяет. Не редактируйте файлы revisions/current вручную: следующее применение их заменит, а hash manifest защищает неизменяемость.

Зависимости и HTTP-зоны загружаются перед маршрутами. В existing-профиле общие HTTP-политики применяются только к virtual hosts APM. Неудачная проверка/активация возвращает предыдущую ревизию. [Операции](operations.md)
