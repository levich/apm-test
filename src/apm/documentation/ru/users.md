# Пользователи

Раздел доступен admin. Создайте пользователя с минимально нужной ролью, затем настройте язык и при необходимости OIDC. Данные MFA управляются самим пользователем в «Безопасности». Изменение роли/доступа отзывает сессии.

## `email`

<!-- setting:email -->
Email входа. Уникальный, приводится к нижнему регистру. Обязателен при создании.

## `password`

<!-- setting:password -->
Пароль не короче 12 символов при создании. Сохранённый хеш не показывается; для восстановления используйте CLI.

## `role`

<!-- setting:role -->
admin управляет всеми разделами, operator маршрутами/ACL/upstream без административных политик, observer только читает. По умолчанию observer.

## `enabled`

<!-- setting:enabled -->
Разрешить вход, по умолчанию true. Нельзя выключить последнего администратора. Изменение отзывает сессии пользователя.

## `language`

<!-- setting:language -->
Предпочтительный язык ru/en; по умолчанию ru. Переключатель интерфейса сохраняет cookie языка.

## `oidc_subject`

<!-- setting:oidc_subject -->
Привязка OIDC в формате issuer|sub, например https://id.example.com|subject-id. По умолчанию null. Не связывается автоматически по email.

## `mfa_enabled`

<!-- setting:mfa_enabled -->
Системный индикатор включённого второго фактора. Меняется подтверждением enrollment или локальным сбросом MFA.
