# DNS-провайдеры

Доступ к API DNS для ACME и ECH. Выберите провайдера, зону и секреты, сохраните и выполните проверку. Проверка подтверждает чтение, а не права записи. Управление доступно только администратору.

## Настройки

### `name`

<!-- setting:name -->
Название ресурса для поиска и выбора в панели, например test. Не меняет его ID и связанные ресурсы.

Формат: `string`. По умолчанию: `обязательно`. Ограничения: minLength=1; maxLength=128.

Пример: `"test"`.

### `enabled`

<!-- setting:enabled -->
Включает объект в генерируемую конфигурацию. Выключенный объект сохраняется в панели. Изменение вступает в силу после сохранения и успешного применения.

Формат: `boolean`. По умолчанию: `true`.

Пример: `true`.

### `provider`

<!-- setting:provider -->
DNS API: Webnames, Yandex Cloud DNS, REG.RU, Selectel v2 или Cloud.ru Evolution. Нужны секреты выбранного провайдера; перечень ниже.

Формат: `string`. По умолчанию: `обязательно`. Ограничения: webnames / yandex / regru / selectel / cloudru.

Пример: `"webnames"`.

### `zone`

<!-- setting:zone -->
DNS-зона без протокола, например example.com. Домены сертификата должны относиться к зоне, доступной этим учётным данным.

Формат: `string`. По умолчанию: `обязательно`.

Пример: `"example.com"`.

### `zone_id`

<!-- setting:zone_id -->
Идентификатор DNS-зоны в API провайдера, если он требуется. Не является именем домена; найдите его в панели провайдера.

Формат: `string`. По умолчанию: `""`.

Пример: `"your-zone-id"`.

### `ttl`

<!-- setting:ttl -->
TTL создаваемой ACME TXT-записи в секундах. Низкое значение ускоряет смену записей, но учитывайте ограничения провайдера.

Формат: `integer`. По умолчанию: `300`. Ограничения: minimum=60; maximum=86400.

Пример: `300`.

### `propagation_timeout`

<!-- setting:propagation_timeout -->
Максимальное ожидание распространения TXT-записи в секундах. При превышении выпуск завершается ошибкой, cleanup удаляет проверочную запись.

Формат: `integer`. По умолчанию: `600`. Ограничения: minimum=30; maximum=3600.

Пример: `600`.

### `discovery_allowed`

<!-- setting:discovery_allowed -->
Разрешить Docker discovery использовать этот DNS-профиль. Само discovery дополнительно включается переменными окружения и списками сетей/доменов.

Формат: `boolean`. По умолчанию: `false`.

Пример: `false`.

### `operator_allowed`

<!-- setting:operator_allowed -->
Разрешить операторам выбирать профиль для запросов DNS-01. Секреты остаются доступны только администратору на запись.

Формат: `boolean`. По умолчанию: `false`.

Пример: `false`.

## Пример работы

Создайте ресурс с понятным названием, заполните обязательные поля и сохраните. Проверьте завершение apply в «Операциях». При ошибке angie -t исправьте параметры или зависимости; прежняя рабочая конфигурация сохраняется. Observer читает данные, admin удаляет ресурсы, которые больше не используются.

## Секреты

Webnames и REG.RU: username/password; Yandex: iam_token либо service_account_id/key_id/private_key; Selectel v2: token либо username/password/domain_name/project_id; Cloud.ru: token либо key_id/secret.

### `username`

<!-- credential:username -->
Имя пользователя API Webnames/REG.RU или IAM Selectel. Используйте отдельную учётную запись с правами только на нужные зоны.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `password`

<!-- credential:password -->
Пароль API Webnames/REG.RU или IAM Selectel. Передаётся только на запись и шифруется; не публикуйте в Docker labels.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `iam_token`

<!-- credential:iam_token -->
Временный IAM token Yandex Cloud. Альтернатива ключу сервисного аккаунта; обновляйте до окончания его срока.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `service_account_id`

<!-- credential:service_account_id -->
ID сервисного аккаунта Yandex Cloud, имеющего доступ к DNS-зоне.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `key_id`

<!-- credential:key_id -->
ID ключа сервисного аккаунта Yandex или access key Cloud.ru; используется вместе с соответствующим приватным ключом/secret.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `private_key`

<!-- credential:private_key -->
PEM приватного ключа сервисного аккаунта Yandex. Вставьте целиком с BEGIN/END и переводами строк.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `token`

<!-- credential:token -->
API token Selectel v2 или Cloud.ru. Альтернатива соответствующему набору IAM/access-key полей.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `domain_name`

<!-- credential:domain_name -->
Имя IAM domain Selectel, не DNS-зона сертификата. Требуется при получении token по имени/паролю.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `project_id`

<!-- credential:project_id -->
ID проекта Selectel, используемый при IAM-аутентификации.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.

### `secret`

<!-- credential:secret -->
Secret access key Cloud.ru Evolution вместе с key_id. Не является паролем пользователя APM.

Формат: строка. По умолчанию: не задано; секрет не показывается после сохранения.
