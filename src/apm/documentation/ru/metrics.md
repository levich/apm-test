# Метрики

Показывает последние доступные метрики Angie и ссылку на GoAccess. Доступно всем пользователям. Worker собирает метрики при периодическом обслуживании; история хранится APM_METRICS_RETENTION_DAYS, не более 10080 точек. Каждая точка содержит время, connections и HTTP requests.

Отчёт GoAccess требует compose.analytics.yaml и runtime access_logs=true, analytics=true. Без доступного агента данные могут отсутствовать или быть старыми; проверьте время сбора. Эти метрики не заменяют проверку каждого backend.
