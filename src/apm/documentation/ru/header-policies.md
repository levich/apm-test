# HTTP-заголовки

Повторно используемые HTTP-заголовки. Создайте политику и подключите к прокси-хосту. Удаление заголовков требует headers_more. Изменение доступно администратору; ошибка модуля сохраняет прежнюю конфигурацию.

## Настройки

### `name`

<!-- setting:name -->
Название ресурса для поиска и выбора в панели, например test. Не меняет его ID и связанные ресурсы.

Формат: `string`. По умолчанию: `обязательно`. Ограничения: minLength=1; maxLength=128.

Пример: `"test"`.

### `enabled`

<!-- setting:enabled -->
Включает объект в генерируемую конфигурацию. Выключенный объект сохраняется в панели. Изменение вступает в силу после сохранения и успешного применения.

Формат: `boolean`. По умолчанию: `true`.

Пример: `true`.

### `response`

<!-- setting:response -->
Заголовки ответа браузеру в формате Header-Name=value, по одному на строке. Пример: Referrer-Policy=same-origin. Значения экранируются компилятором.

Формат: `object`. По умолчанию: `{}`.

Пример: `{"Referrer-Policy": "same-origin"}`.

### `upstream`

<!-- setting:upstream -->
Заголовки запросов к приложению в формате Header-Name=value. Используйте только доверенные фиксированные значения.

Формат: `object`. По умолчанию: `{}`.

Пример: `{"X-Application": "example"}`.

### `remove`

<!-- setting:remove -->
Имена заголовков ответа для удаления, по одному на строке. Требуется модуль headers_more; без него применение отклоняется.

Формат: `array`. По умолчанию: `[]`.

Пример: `["X-Powered-By"]`.

### `hsts`

<!-- setting:hsts -->
Отправляет Strict-Transport-Security с max-age=31536000. Включайте после проверки рабочего HTTPS: браузер запоминает обязательность TLS.

Формат: `boolean`. По умолчанию: `false`.

Пример: `false`.

### `hsts_subdomains`

<!-- setting:hsts_subdomains -->
Добавляет includeSubDomains в HSTS. Все поддомены также должны поддерживать HTTPS; действует при включённом hsts.

Формат: `boolean`. По умолчанию: `false`.

Пример: `false`.

### `frame_options`

<!-- setting:frame_options -->
Политика X-Frame-Options: upstream сохраняет ответ приложения; DENY запрещает встраивание, SAMEORIGIN разрешает свой origin, remove удаляет заголовок.

Формат: `string`. По умолчанию: `"upstream"`. Ограничения: upstream / DENY / SAMEORIGIN / remove.

Пример: `"upstream"`.

## Пример работы

Создайте ресурс с понятным названием, заполните обязательные поля и сохраните. Проверьте завершение apply в «Операциях». При ошибке angie -t исправьте параметры или зависимости; прежняя рабочая конфигурация сохраняется. Observer читает данные, admin удаляет ресурсы, которые больше не используются.
