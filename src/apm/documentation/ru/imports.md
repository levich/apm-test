# Импорт и резервные копии

Доступно администратору. Сначала экспортируйте read-only snapshot NPM/NPMPlus командой apm export-npm, загрузите JSON/ZIP и выполните preview. Отчёт показывает поддержанные и пропущенные объекты; не считайте неизвестные параметры перенесёнными. «Создать выключенные черновики» сохраняет ресурсы выключенными; «Активировать» создаёт конфигурацию и ставит apply. Конфликты доменов и ссылок требуют исправления.

Перед резервным копированием задайте локально apm backup-password: минимум 16 символов. Кнопка backup ставит создание зашифрованного .apm архива в очередь. Архив содержит базу и ключи, храните его отдельно. Восстановление выполняется apm restore ARCHIVE при остановленных manager и worker, с паролем; прежний каталог сохраняется. После старта дождитесь проверки и применения. [CLI](cli.md)
