# Безопасность аккаунта

Настройка TOTP доступна текущему пользователю. Введите текущий пароль, начните enrollment, добавьте показанный otpauth URI в приложение-аутентификатор и подтвердите одноразовый код. Сохраните recovery codes: после подтверждения они показываются один раз. URI содержит секрет, не публикуйте его.

При входе после пароля потребуется TOTP или ещё не использованный recovery code. Восстановление администратором выполняется локально: apm reset-password EMAIL --reset-mfa. Команда отзывает все сессии пользователя. OIDC включается системными настройками; заранее привяжите oidc_subject существующему пользователю.
